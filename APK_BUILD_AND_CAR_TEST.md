# Mazda Monitor 2.0 — сборка APK и проверка на Mazda CX-5

## Статус проверки
- Самостоятельные тесты чистой Java: 43/43.
- Дополнительные имитационные тесты поточного диалога с ELM327: 9/9.
- Компиляция Android APK: **не выполнена** (здесь нет Android SDK/Gradle и нет доступа к репозиториям).
- Испытание приложения на вашем Mazda CX-5: **не выполнено** (нет доступа к автомобилю и Bluetooth).
- Скриншоты Car Scanner подтверждают, что **Car Scanner** получал данные от ЭБУ, но это не проверка Mazda Monitor.

## Получение APK без Android Studio: GitHub Actions
1. Создайте репозиторий в своём аккаунте GitHub, например `MazdaMonitor`.
2. Распакуйте архив и загрузите файлы **содержимого** папки проекта в корень репозитория, включая каталог `.github`.
3. В GitHub перейдите `Actions` → `Build Android APK` → `Run workflow` (или дождитесь выполнения после `push` в `main`).
4. При успешном завершении откройте запуск workflow и скачайте артефакт `MazdaMonitor-debug-apk`.
5. Распакуйте скачанный архив: внутри `app-debug.apk`, который можно установить на Android.
6. Если сборка завершилась с ошибкой, откройте её лог — ошибку нужно исправить до установки.

## Альтернатива: Android Studio
1. Откройте распакованный проект через Android Studio.
2. Установите Android SDK Platform API 35, Build Tools 35.0.0, Gradle 8.11.1, JDK 17.
3. Выполните Gradle Sync и Build → Build APK(s).
4. Результат успешной сборки: `app/build/outputs/apk/debug/app-debug.apk`.

## Первый тест на настоящем автомобиле (машина неподвижна)
1. Установите APK. Включите зажигание и подключите ELM327 к диагностическому разъёму.
2. В настройках Android выполните сопряжение Bluetooth с ELM327 (обычно OBDII, PIN 1234 или 0000).
3. Откройте Mazda Monitor → Панель → Выбрать ELM327 → Подключить; дайте разрешение на устройства поблизости.
4. На вкладке Датчики оставьте на первом испытании только 010C (обороты), 0105 (ОЖ), 0142 (напряжение ЭБУ), 010D (скорость), 0106 (STFT), 0107 (LTFT).
5. На работающем на холостом ходу двигателе проверьте, что значения меняются и примерно сопоставимы с Car Scanner. При заглушённом двигателе обороты должны быть ноль.
6. Затем добавьте 0159 (давление рейки), 010B (MAP), 0110 (MAF), 012F (уровень топлива).
7. Через вкладку Топливо экспортируйте CSV для анализа реальных значений и частоты обновления. Проверьте достоверность по Car Scanner и приборной панели.
8. Не выбирайте десятки датчиков сразу: задержки адаптера по скриншотам достигают секунд на один запрос.

Если Mazda Monitor не подключается, запишите сообщение о соединении или сделайте скриншот ошибки. Это определит, нужен ли дополнительный вариант настройки ELM327 или изменение логики чтения.

## Безопасность
Приложение использует стандартные OBD2-команды чтения, а не сброс ошибок и не команды управления автомобилем. Не используйте телефон во время вождения. Первую проверку делайте на стоянке.
